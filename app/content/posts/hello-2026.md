# Hello from 2026

This post was added in **August 2026** as part of the preservation revival
of BlogDown, to prove the markdown pipeline still renders end-to-end.

If you are reading this in a browser, the whole 2017 stack still works:

* `webcomponents-lite` polyfills (HTML imports, custom elements v0)
* Polymer 1.x with shady DOM
* `marked-element` markdown rendering
* `page.js` hashbang routing

> Zero compilation, still.
